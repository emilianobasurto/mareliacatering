MARELIA CATERING — WEB PARA AZURE STATIC WEB APPS

PUBLICACIÓN
1. Subir el contenido completo de esta carpeta al repositorio o al servicio de Azure Static Web Apps.
2. En Azure, usar esta carpeta como "App location" y dejar vacío "Api location".
3. Como no necesita compilación, indicar esta misma carpeta como "Output location" o usar la raíz del paquete según el método de carga.
4. Vincular el dominio mareliacatering.com.ar desde la sección "Custom domains" de Azure.

REEMPLAZO DE FOTOS
Las imágenes están en assets/images. Para cambiarlas sin modificar código, reemplazar los archivos conservando estos nombres y proporciones aproximadas:
- hero-pizza.webp — foto principal horizontal (recomendado 1536 × 820 o mayor)
- empanadas.webp — servicio Producción (horizontal 3:2)
- horno-en-vivo.webp — servicio En Vivo (horizontal 3:2)
